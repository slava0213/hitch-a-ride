# 🚗 Сервис поиска попутчиков

Веб-приложение для поиска попутчиков: поездки, заявки, чат, отзывы.

## 🔗 Ссылки

- **Репозиторий:** https://github.com/slava0213/hitch_a_ride
- **Демо (Render):** https://hitch-a-ride.onrender.com

## 🛠 Стек

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js + Express
- **Авторизация:** JWT (httpOnly cookie) + bcrypt
- **Хранилище:** JSON-файл (`carpool.json`)

## ✨ Возможности

- Регистрация и вход
- Создание поездок
- Поиск по маршруту и дате
- Заявки (подача, приём, отклонение)
- Живой чат с индикатором «печатает...» и онлайн-статусом
- Отзывы и рейтинг водителей

## 🚀 Локальный запуск

```bash
cd server
npm install
npm start
```
